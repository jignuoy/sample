1. 노트북 설정  
-. 윈도우11 pro (OS 환경 확인)  
-. 오피스 2021 (문서 확인용)
-. V3 Lite (사내 보안 프로그램)
-. Git (버전 관리 툴 설치 및 `git --version` 작동 확인)
-. DBeaver (데이터베이스 클라이언트 / 운영 DB 및 MyBatis 쿼리 검증용)

3. frontend (Vue 3)
-. node.js (버전확인: 운영 환경에 맞춰 설치 후 터미널에서 `node -v`로 확인)
-. VSCODE (프론트엔드 메인 IDE 설치)
-. Vue Official (구 Volar / VSCode 확장 프로그램 - Vue 3 필수)
-. Prettier (VSCode 확장 프로그램 - 코드 포맷 자동 정렬)
-. ESLint (VSCode 확장 프로그램 - 실시간 문법 에러 체크)

4. backend (Spring Boot)
-. jdk (버전확인: Spring Boot 버전에 상응하는 JDK 설치 후 `java -version`으로 확인)
-. STS (1안: 기존 Eclipse 기반 개발 환경 선호 시 설치)
-. IntelliJ (2안: 스프링 부트 및 Gradle/Maven 효율 극대화 시 설치)
-. Lombok (IDE 플러그인 설치 및 Enable Annotation Processing 활성화 필요)
-. MyBatisX (IDE 플러그인 설치 - Java 인터페이스와 XML 매퍼 파일 간 이동용)

5. 기타 툴
-. Postman (Spring Boot REST API 독립 테스트 및 JSON 데이터 검증용)
   => 크롬 확장프로그램 YARC (Yet Another REST Client / REST API 테스트 및 JSON 데이터 검증용)

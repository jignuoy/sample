# 🛠️ Spring Boot + Vue 3 운영 프로젝트 로컬 개발 환경 구축 가이드

본 문서는 현재 운영 중인 `Spring Boot (MyBatis)` + `Vue 3 (Vite)` 시스템의 추가 개발 및 유지보수를 위해 로컬 PC에 필요한 개발 도구와 설정 방법을 정리한 가이드입니다.

---

## 1. ⚙️ 필수 런타임 환경 (Runtime)

기존 운영 소스 코드의 버전을 맞추는 것이 가장 중요합니다. 프로젝트의 실제 버전을 반드시 확인 후 설치하세요.

*   **Node.js (LTS 버전)**: Vue 3 빌드 및 패키지 관리(`npm` 또는 `yarn`)를 위해 필수입니다.
*   **Java Development Kit (JDK)**: 운영 중인 Spring Boot 버전에 맞춘 JDK를 설치합니다.
    *   *Spring Boot 2.x 기반인 경우 -> **JDK 8 또는 11***
    *   *Spring Boot 3.x 기반인 경우 -> **JDK 17 이상***
*   **데이터베이스 클라이언트**: 운영/개발 DB에 접속하여 iBatis에서 MyBatis로 전환된 SQL 쿼리를 직접 검증할 도구입니다.
    *   *추천 도구: DBeaver (오픈소스, 통합 DB 지원), Toad, SQL Developer 등*

---

## 2. 💻 프론트엔드 로컬 세팅 (Vue 3)

### ① IDE: VS Code (Visual Studio Code)
프론트엔드 소스 관리 및 컴포넌트 수정을 위해 사용합니다.

### ② 필수 확장 프로그램 (Extensions)
*   **Vue Official (구 Volar)**: **(필수)** Vue 3 문법 강조, 자동 완성을 지원합니다. (기존 레거시용 Vetur가 설치되어 있다면 반드시 비활성화하세요.)
*   **Prettier - Code formatter**: 기존 운영 코드의 포맷 규칙(들여쓰기 등)을 깨뜨리지 않고 유지하기 위해 사용합니다.
*   **ESLint**: 실시간 문법 및 코드 스타일 검사 도구입니다.

### ③ 로컬 구동 절차
1.  VS Code로 프론트엔드 소스 폴더를 엽니다.
2.  터미널(`Ctrl + ~`)을 열고 의존성 패키지를 설치합니다.
    ```bash
    npm install  # 또는 yarn install
    ```
3.  환경 변수 파일(`.env.development` 등)에서 **API 서버 주소(백엔드 로컬 포트)**가 올바르게 지정되어 있는지 확인합니다.
4.  로컬 개발 서버를 실행합니다.
    ```bash
    npm run dev  # 또는 npm run serve
    ```

## 3. ☕ 백엔드 로컬 세팅 (Spring Boot & MyBatis)

### ① IDE: IntelliJ IDEA (권장) 또는 STS / Eclipse
이미 빌드된 환경이므로 전자정부프레임워크나 Eclipse 계열보다는 스프링 부트 및 Gradle/Maven 프로젝트 열기가 수월한 **IntelliJ**를 권장합니다.

### ② 필수 플러그인 & 설정
*   **MyBatisX (IntelliJ 플러그인)**: **(강력 추천)** iBatis에서 MyBatis로 전환되면서 XML 매퍼 구조를 많이 사용할 텐데, Java 인터페이스 파일과 XML 매퍼 쿼리문 사이를 아이콘 클릭 한 번으로 이동시켜 주는 필수 플러그인입니다.
*   **Lombok**: 데이터 모델(DTO, VO)의 Getter/Setter 플러그인입니다. (IDE 내 Enable Annotation Processing 체크 필수)

### ③ 로컬 구동 및 쿼리 검증 절차
1.  `pom.xml` (Maven) 또는 `build.gradle` (Gradle) 파일이 있는 루트 폴더를 IDE로 오픈(Import)합니다.
2.  `application.yml` 또는 `application.properties` 파일에서 **로컬 또는 개발(DEV) 환경의 DB 접속 정보**와 **MyBatis 매퍼 경로 설정**을 확인합니다.
3.  iBatis에서 `#변수#`였던 문법이 MyBatis에서 `#{변수}`로 정상 전환되었는지, 로컬에서 호출하며 쿼리 에러 여부를 체크합니다.

## 4. 🌐 API 및 네트워크 검증 도구

프론트엔드 화면(Vue 3) 없이 백엔드 기능만 따로 검증하거나, 통신 데이터 구조를 파악할 때 사용합니다.

*   **Postman**: 기 생성된 Spring Boot의 REST API 호출 테스트 및 Request/Response 데이터(JSON) 구조 확인용.
*   **브라우저 개발자 도구 (F12)**: Vue 3 화면에서 백엔드로 요청을 보낼 때 **CORS 에러**가 나거나 헤더에 **토큰/세션 정보**가 누락되는지 `Network` 탭에서 실시간 모니터링 시 사용.

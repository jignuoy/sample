1. 노트북 설정 <br>
-. 윈도우11 pro (OS 환경 확인) <br>
-. 오피스 2021 (문서 확인용) <br>
-. V3 Lite (사내 보안 프로그램) <br>
-. Git (https://git-scm.com / 버전 관리 툴 설치 및 `git -v` 작동 확인 / 버전(git version 2.55.0.windows.3)) <br>
-. DBeaver (https://dbeaver.io / 데이터베이스 클라이언트 / 운영 DB 및 MyBatis 쿼리 검증용 / 버전(DBeaver Community 26.1.3)) <br>

2. frontend (Vue 3) <br>
-. node.js (버전확인: 운영 환경에 맞춰 설치 후 터미널에서 `node -v`로 확인) <br>
-. npm (버전확인: node.js 설치 시 자동 설치되며 터미널에서 `npm -v`로 버전 일치 여부 확인) <br>
-. VSCODE (프론트엔드 메인 IDE 설치) <br>
-. Vue Official (구 Volar / VSCode 확장 프로그램 - Vue 3 필수) <br>
-. Prettier (VSCode 확장 프로그램 - 코드 포맷 자동 정렬) <br>
-. ESLint (VSCode 확장 프로그램 - 실시간 문법 에러 체크) <br>

3. backend (Spring Boot) <br>
-. jdk (버전확인: Spring Boot 버전에 상응하는 JDK 설치 후 `java -version`으로 확인) <br>
-. STS (1안: 기존 Eclipse 기반 개발 환경 선호 시 설치) <br>
-. IntelliJ (2안: 스프링 부트 및 Gradle/Maven 효율 극대화 시 설치) <br>
-. Lombok (IDE 플러그인 설치 및 Enable Annotation Processing 활성화 필요) <br>
-. MyBatisX (IDE 플러그인 설치 - Java 인터페이스와 XML 매퍼 파일 간 이동용) <br>

4. 기타 툴 <br>
-. 크롬 확장프로그램 YARC (Yet Another REST Client / REST API 테스트 및 JSON 데이터 검증용) <br>

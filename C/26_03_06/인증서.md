# [롯*온] Spring Boot Gateway SSL 설정 정리 (Windows / Java8 기준)

## 1. 전체 시스템 구조

``` 
브라우저  
   ↓  
https://test.lotte.com/product/L1234466  
   ↓  
Gateway 서버 (Spring Boot, 443 SSL)  
   ↓  
Java API 서버  
   ↓  
Vue 페이지
``` 

``` 
Gateway
 └ 443 SSL 필요

Java API
 └ 내부 호출 → SSL 필요 없음

Vue
 └ Gateway 통해서만 접근
``` 

SSL은 Gateway 서버에서만 필요하다.

------------------------------------------------------------------------

## 2. 인증서 파일

공급처에서 받은 파일
``` 
allgw-tst.crt
allgw.key
allgw.jks
``` 
| 파일  | 역할             |
| --- | -------------- |
| crt | 서버 인증서         |
| key | 개인키            |
| jks | Java용 keystore |

Spring Boot에서는 보통 **jks만 사용**한다.

------------------------------------------------------------------------

## 3. application.yml (정상 구조)

``` yaml
server:
  port: 443

  ssl:
    key-store: classpath:allgw.jks
    key-store-password: 비밀번호
    key-store-type: JKS
```

trust-store 설정은 대부분 필요 없다.

삭제 대상:

    trust-store
    trust-store-password

------------------------------------------------------------------------

## 4. key-store vs trust-store
  
| 설정          | 의미            |
| ----------- | ------------- |
| key-store   | 내가 사용할 서버 인증서 |
| trust-store | 내가 신뢰할 외부 인증서 |

현재 구조
```
브라우저 → Gateway
```
따라서 
```
**key-store만
```
필요**하다.

------------------------------------------------------------------------

## 5. Java 실행

정상 실행

    java -jar gateway.jar

또는

    java -Xms512m -Xmx1024m -jar gateway.jar

불필요한 옵션

    -Djavax.net.ssl.trustStore=

이 옵션이 있으면 Java 기본 cacerts를 사용하지 못할 수 있다.

------------------------------------------------------------------------

## 6. Java8 기본 인증서 위치

Java8

    JAVA_HOME/jre/lib/security/cacerts

예

    C:\Program Files\Eclipse Adoptium\jdk-8.0.482.8-hotspot\jre\lib\security\cacerts

여기에는 다음 루트 인증서들이 포함되어 있다.

-   Amazon Root CA
-   DigiCert
-   GlobalSign
-   Let's Encrypt

이미 약 100개 이상의 인증서가 포함되어 있다.

PowerShell
```
& "C:\Program Files\Eclipse Adoptium\jdk-8.0.482.8-hotspot\bin\keytool.exe" -list -keystore "C:\Program Files\Eclipse Adoptium\jdk-8.0.482.8-hotspot\jre\lib\security\cacerts" -storepass changeit | Select-String Amazon
```

------------------------------------------------------------------------

## 7. Windows 브라우저 인증서

브라우저 경고 제거용

    certmgr.msc

설치 위치

    신뢰할 수 있는 루트 인증 기관

주의

이것은 **브라우저용 인증서**이며 Java와는 별개이다.

------------------------------------------------------------------------

## 8. 프로젝트 A와 B 차이

### 프로젝트 A

-   trust-store 없음
-   Java 기본 cacerts 사용
-   정상 동작

### 프로젝트 B

-   trust-store = allgw.jks
-   JDK cacerts 사용 안함
-   allgw.jks만 신뢰

문제

    allgw.jks
    └ 서버 인증서만 있음

Intermediate CA가 없어 SSL 오류 발생
